# 07: Trademark lookalike check, M1 "The Frame"

## Verdict

**M1 is not clear to take forward as Facework's registrable mark.**

1. **A live US registration is nearly the same construction, in a class that
   covers design studios.** Reg. **3630396** (Synchronous Media International,
   class 35 including logo creation and branding) is four heavy, square-capped,
   unconnected corners around an empty square. I viewed the registered drawing.
   M1 differs only in proportion (4:5 vs square) and color (black vs claimed
   red). Neither is enough distance. **Likelihood of confusion, M1 alone:
   strong.**
2. **The motif is generic.** It's a Unicode character (U+26F6 "Square Four
   Corners"), Google's stock `crop_free` icon, and a logo-template staple. It
   can't carry Facework's identity distinctively, and protection would be thin
   even if registered.

**Call: fall back to M2** (the current Coherence Mark redrawn at the wordmark's
stroke) as the identity mark. **Keep The Frame as an unregistered system
device:** the verdigris attention box from 05-motion P3. Being generic is fine,
even useful, for an interface behavior people already read as "checking."

This changes the 06 recommendation. A distinguishing change to M1 isn't worth
it: anything that makes it ownable (a filled center, an added element) breaks
the open, empty center that was its meaning.

**Separately, the name needs clearance.** "Facework" is the title of Kyle
McDonald's 2020 face-recognition game (Mozilla Creative Media Award, IDFA
DocLab), which sits right on Facework's subject. No USPTO registration for it
was found, but its use on the same topic is the name risk that matters most.

> **Ask a trademark attorney before registering anything.** This is a designer's
> lookalike search, not a clearance opinion. Counsel should pull the full file
> histories for Reg. 3630396 and 3187941, run EUIPO/WIPO (unreachable here), and
> assess the "Facework" name against McDonald's prior use.

## 2. Live brands (unregistered use)

**No live brand found in media, publishing, research, archives, identity
verification or design studios whose primary mark is open corners around an
empty field.**

Checked with no close match:
- Magnum Photos, Frame magazine, Framer, Frame.io
- Jumio, Veriff, ID.me, CLEAR, Persona, World ID, FaceTec

## 4. What changes

- **06-mark-study §9:** recommendation moves from M1 to **M2 as the identity
  mark**. The Frame becomes the attention box (system device, unregistered).
- The mark-and-motion idea survives in a split form. The identity mark (M2) has
  its own entrance: it cuts on complete and holds, per FN-01. The Frame carries
  the system's verification behavior.
- The issue numerals (built from the wordmark) are unaffected.
