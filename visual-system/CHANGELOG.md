# Facework Visual Specification Changelog

## 0.1.0 — 2026-08-06

### Added

- FVS-000 framework and authority model.
- FVS-100 Visual Constitution.
- FVS-110 canonical visual lexicon.
- FVS-200 seven visual primitives and protocol mapping.
- FVS-300 through FVS-900 normative practice specifications.
- FVR-000 Atlas research method and five initial synthesis studies.
- Artifact record and reference-study templates.
- Machine-readable artifact metadata schema and registry.
- Foundational architecture decision record.

### Resolved

- FVS-000 is the framework; FVS-100 is the Constitution.
- Visual primitives are separate from protocol primitives.
- Existing prototype and design-infrastructure files are implementations, not
  automatic sources of visual law.
- Paper and dark expressions are coordinated modes.
- Berkeley Mono is the preferred structural voice; sustained reading receives a
  dedicated reading role.
- The butterfly / Coherence Mark is provisional pending derivation.

### Open

- Typeface trials across all application classes.
- Reconciliation of reference design tokens with FVS-500 and FVS-600.

## Identity 1.0.0 — 2026-08-06

### Added

- FVI-200 Identity Lockups and Spatial Protocol.
- Established x-based spacing, four responsive signature configurations,
  placement zones, co-branding, descriptor, and production rules.
- Added construction, responsive-selection, and placement reference boards.
- FVI-300 Symbol and Diagram Grammar.
- Added seven production symbols, a canonical knowledge-lineage map, line and
  state semantics, and ambiguity tests.
- FVI-400 Motion Signature.
- Established Exchange Resolve as the canonical four-phase identity motion.
- Added a self-contained animated SVG, reusable CSS tokens, an interactive HTML
  reference, a four-frame storyboard, and reduced-motion behavior.

### Resolved

- The mark, logotype, lockup, diagram, and motion layers now form one complete
  foundational identity program.
- Axis Exchange remains identity and never becomes a generic diagram node.
- Responsive identity changes configuration before it loses legibility.
- Motion expresses relationship and stabilization without literal butterfly
  behavior or decorative convergence.

### Open

- Trademark clearance before registration or high-cost rollout.
- Physical-production, projection, and representative-device testing.
- Application translation under FVS-900.

## Applications 1.0.0 — 2026-08-06

### Added

- FVA-000 Open Ledger application foundation with an explicit canonical-source
  boundary excluding pre-FVS prototypes from design authority.
- FVA-100 responsive public knowledge interface with current attention,
  knowledge path, artifact filtering, print adaptation, and accessible mobile
  navigation.
- FVA-200 seven-page field-note publication with real headings, selectable text,
  image alternatives, repeated table headers, and preserved lineage.
- FVA-300 eight-frame presentation reference with speaker-note sources and
  editable text.
- FVA-400 statement, evidence, and sequence social templates.
- FVA-500 threshold, wayfinding, and artifact-plaque environmental design intent.
- FVA-600 responsive Lineage Inspector product reference with map/list views,
  evidence, and canonical record panels.
- Shared cross-medium application tokens derived from FVS-300, FVS-500,
  FVS-600, and FVS-800.

### Resolved

- Rejected the first-pass serif-led application direction as inconsistent with
  the current FVS-500 neutral reading role.
- Established Register as identity only, structural mono for metadata, and a
  neutral sans for reading and interfaces.
- Established semantic color, visible lineage, open intervals, and variable
  density as the cross-medium continuity behaviors.

### Open

- Trademark clearance for high-cost identity deployment.
- Physical material, tactile, code, and fabrication review.
- Representative projection, device, platform-compression, and user testing.

## Facework Field 0.1.0 — 2026-08-06

### Added

- FVA-610 specification for a weekly, local-first reflection ritual.
- A responsive single-player reference with three declared inputs, a bounded
  Lorenz mapping, optional Face Note, and browser-local archive.
- A synthetic collective-field simulation containing no participant data.
- Visible privacy, epistemic, mathematical, reduced-motion, and multiplayer
  release boundaries.

### Resolved

- Facework Field is an experiment under FVS-900, not the face.works homepage.
- A generated trace is a reflective representation, not an identity measure,
  biometric signature, diagnosis, or alternate Coherence Mark.
- Multiplayer remains gated; the current reference performs no network writes.

### Open

- Prompt comprehension and repeated-use evaluation.
- Real-device touch, screen-reader, performance, and reduced-motion testing.
- Privacy, moderation, retention, deletion, aggregation, and threat-model review
  before any participant-backed collective field.
