# FVA-100 — Website

The website is the public interface to a living discipline, not a marketing
funnel, portfolio, or exposed repository. It opens with a current observation,
reveals the knowledge path, and provides a dense artifact index where claim,
type, status, and lineage can be compared.

## Human experience / canonical architecture

Public navigation follows curiosity while metadata preserves the system beneath
it.

| Public path | Canonical role |
|---|---|
| Field Notes | living observations across theory, discipline, and practice |
| Models | Cultural Physics and other ways of seeing |
| Frameworks | Coherence Design, specifications, standards, and protocols |
| Cases | evidence and reference implementations |
| Conversations | dialogue that refines the discipline |
| Experiments | hypotheses, prototypes, and protocol iterations |
| Library | reading, listening, watching, artifacts, references, and lineage |
| About | the practitioner and institution behind the work |

The homepage is a public archive of pattern recognition. It foregrounds what
Facework is paying attention to now, then lets a reader move from fast-changing
observation toward slower, more durable knowledge. A claim may reveal its
related model, framework, standard, application, and evidence without requiring
the reader to understand repository taxonomy first.

The reference uses a 12-column open ledger, a persistent orientation rail, one
semantic Clarity signal, and a reading-first hierarchy. On small screens the
rail becomes a compact header, comparisons become sequences, and metadata moves
before the content it qualifies. All controls are keyboard operable, at least
44 pixels high, and retain visible focus. Print removes navigation while
preserving titles, metadata, URLs, and lineage.
