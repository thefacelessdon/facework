# FVA-200 — Publications

Publications are durable knowledge objects. The page is an open ledger: a
narrow structural rail carries ID, state, and sequence while the reading field
carries argument and evidence. Register appears once at the threshold. Running
prose uses the canonical reading voice (Literata); Spline Sans Mono is reserved
for metadata, tables, and captions.

Every document preserves selectable text, real headings, page numbers, image
alternatives, repeated table headers, version, status, and source relationships.
It remains useful in monochrome and at ordinary office-print quality.
