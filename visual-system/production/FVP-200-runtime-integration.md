# FVP-200 — face.works Runtime Integration

## Integrated decisions

- The canonical Axis Exchange / Register lockup identifies the public runtime.
- The FVA-100 eight-path architecture governs top-level navigation.
- Paper mode carries reading, comparison, evidence, and deep records.
- Field mode is reserved for the homepage threshold and Facework Field.
- Public Sans carries display and reading roles; JetBrains Mono carries
  identifiers and structural metadata.
- Open ledgers, rules, bilateral relationships, and variable intervals replace
  rounded card grids and decorative dashboard surfaces.
- Every primary navigation target exposes `aria-current`, 44-pixel targets, and
  a mobile index transformation.
- Existing System, Proof, Status, and Engage routes remain available as deep
  reads instead of controlling the public information architecture.
- FVA-610 is distributed as a self-contained `/field/index.html` experiment
  with local-only storage and no participant-backed collective data.

## Retired runtime influence

The decorative Pattern Field, primitive abbreviation bar, and first-pass
artboard route were moved from active source into historical evidence. The
previous runtime DESIGN document was preserved before a new production contract
replaced it.

## Dependency boundary

The runtime packages fonts locally and performs no third-party font request.
Next.js and its lint configuration were moved to the patched 16.3.0 line. The
package audit reports no known vulnerabilities at the time of validation.

## Status

This implementation is suitable for content review and deployment preparation.
It is not silently classified as a public production release.
