# Design Evaluation — face.works home (`/`)

## Verdict: fail

The home page is strongly on-brand: it is the reading room speaking, the
reading is the unit, CTAs are ink, and there are no gradients, shadows, cards,
radii, centered blocks or exclamation points anywhere on the rendered page. It
fails the `must` threshold on **one** contract rule: the CoherenceVerdict
marker colors an **open** (developing) state with the reserved **settled**
green, so shape and color disagree about the reading's state. That is a
one-line CSS defect shared by every verdict on the site. Two `should`-level
findings (motion literals and nav register) and one contract ambiguity
(display face) are recorded for follow-up.

## Component contract findings

- **coherence-verdict**: must violations — "lit bars in --rr-accent, unlit in --rr-line; marker follows the shape law": the marker's *shape* follows the law (square for open) but its *color* is `--rr-settled` in every state, because `.rr-verdict__marker` sets `background: var(--rr-settled)` and neither modifier overrides it (`reading-room.css`, CoherenceVerdict block). Shape-marker's contract is open = square in `--rr-muted`.
- **coherence-verdict**: must_not violations — none.
- **shape-marker** (index rows): none.
- **ink-cta**: none. Transition duration is a literal (S1), a should-level finding.
- **reading-index**: none. Title hover duration is a literal off the FVI-400 scale (S1).
- **record-label**, **display**, **section-head**, **reading**, **coherence-mark**: none.
- Taste clauses breached: status-reserved, color-classifies (C1, must); structural-motion (S1, should); uppercase-labels-only, verdigris-attended (S2, should).

### Findings

- **C1 (must) — open verdict wears settled green.** `FN-027` renders `3/5 · developing` with a green square. Square says *open*; green says *settled*. The status palette is permanently spoken-for (clause: status-reserved) and a hue may appear only where that state is real (clause: color-classifies). Drifting toward OFF-6 (a status hue spent where the state is not real).
- **S1 (should) — motion literals.** `.rr-index__title` transitions color over `160ms`, which is not one of the six FVI-400 durations; `.rr-cta` uses `180ms`, which equals `--rr-motion-quick` but is typed as a literal. Easing is correctly `--rr-ease-settle` in both (clause: structural-motion). Neither is visible as a defect today; both will drift silently if FVI-400 moves.
- **S2 (should) — site rail nav register.** Nav labels are uppercase Schibsted at label size; DESIGN.md §5 reserves uppercase for short *mono* labels (clause: uppercase-labels-only). The active item adds an `--rr-surface` panel fill on top of the `--rr-verdigris-text` color; verdigris alone marks the attended state (clause: verdigris-attended). Source is `globals.css` `.site-nav`, which predates the `.rr` primitives.
- **A1 (contract ambiguity, not scored as a violation) — display face.** DESIGN.md §5's scale table says Display is "Schibsted 800"; the shipped `.rr-display` is `--rr-font-reading` 600 with a comment citing §5 ("the reading room speaks in Literata"). `components.yaml` follows the shipped site. DESIGN.md should be amended to say which one is canon, then the other brought into line.
